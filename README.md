# daftar-alwaseet-site

Public pages for the iPhone and Android app «دفتر الوسيط», served by GitHub Pages from the root of `main`:

- https://tornidomaroc-web.github.io/daftar-alwaseet-site/ (index and data credits)
- https://tornidomaroc-web.github.io/daftar-alwaseet-site/privacy.html (privacy policy, linked from the app's Settings and from App Store Connect)
- https://tornidomaroc-web.github.io/daftar-alwaseet-site/support.html (support and contact, App Store Connect's Support URL)
- https://tornidomaroc-web.github.io/daftar-alwaseet-site/terms.html (terms of use, linked from the index)

Static HTML only: no scripts, no analytics, no external fonts, no build step and no Actions workflow.
